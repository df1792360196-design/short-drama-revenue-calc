# 短剧收益核算工具

一个**单文件、离线、零安装**的本地工具：把甲方发来的「原生剧集挂载数据明细」丢进去，配上你自己的账号名单，自动拆出属于你的那一份收益，按 **归属人 → 分组 → 账号 → 剧目** 四层汇总，并一键导出 Excel。

面向短视频/短剧分发行业：一批账号同时打多部剧，甲方按剧出表，号商需要把总表里自己那部分摘出来对账分钱。

> 🌐 **在线使用**：https://df1792360196-design.github.io/short-drama-revenue-calc/
> 📦 **仓库地址**：https://github.com/df1792360196-design/short-drama-revenue-calc
>
> 在线版同样是纯前端运行，你的数据不会上传到任何服务器。

## ✨ 特性

- **单个 HTML 文件**：双击用浏览器打开就能用，不用装 Python / Node / Excel，也不依赖任何运行环境
- **完全离线**：Excel 解析库已内联进文件，**断网可用**
- **数据不出本机**：所有计算都在浏览器本地完成，没有任何服务器上传，收益数据不会离开你的电脑
- **多表合并**：甲方一个剧一份表时，一次全选多份或分多次拖入，按列名自动合并，并自动跳过名单类工作表
- **四层汇总**：归属人 / 分组 / 账号 / 账号×剧目，另附按日期、按剧目汇总和原始明细
- **归属人自动归并**：分组名去掉「第X批 / 第X组」后的前缀即归属人（`张三第一批` + `张三第二批` → `张三`），并带归并预览可核对
- **对账**：填甲方自有官方号做排除，直接算出「应付总盘」与「其中属于你」，和甲方给的金额对得上
- **日期维度**：统计周期横幅、按日期汇总、日期筛选，导出的文件名自动带日期，方便每天截图对账
- **导出**：一键导出 9 个 sheet 的 Excel，或各表单独导出 CSV

把它们分别拖进第 1 步和第 2 步，点「开始核算」就能看到完整效果。排除名单里填 `示例剧场官方号` 可以看对账效果。

## 📖 使用步骤

| 步骤 | 做什么 |
|---|---|
| **1** | 把甲方发来的表拖进去。一个剧一份表就按住 Ctrl 一次全选多份，或分几次拖入。列名会自动识别，认错了手动改下拉框；表头不在第一行改「表头所在行」。 |
| **2** | 把你的账号名单拖进去，或直接粘贴。名单至少要含 `uid` 和 `分组名称`。加载后看一眼「归并预览」，确认每个分组归给谁没串。 |
| **3** | 选匹配依据（默认按 uid / 视频号ID，最准）、金额口径（默认直接取「剧集总收入」），排除名单填甲方自有官方号。 |
| **4** | 点「开始核算」，看结果；点「导出完整 Excel」拿成品。 |

### 关于「金额口径」

- **直接取「剧集总收入」**（默认，绝大多数情况）：甲方表中每行 = 一个账号一条视频一部剧，`剧集总收入` 已经是该账号自己赚的钱，直接筛选汇总即可。
- **按播放量占比分摊**：只在甲方给的是**整部剧的总盘**（每行都重复填同一个总额）时才用，工具会按各账号播放量占比摊到每个账号。

判据很简单：同一部剧里，如果各账号的 `剧集总收入` 数值互不相同，就是「已经分摊到行」，用默认口径；如果所有行都是同一个数，说明是总盘，才用分摊。

## 🔑 归属人归并规则

一个提供账号的人账号太多时会分成多组，命名一般是「人名 + 第几批」。规则：

```
分组名去掉「第X批 / 第X组 / 第X期」后的前缀 = 归属人

张三第一批  → 张三
张三第二批  → 张三
李四第一批  → 李四
王五        → 王五
```

**不同人互不混淆**：`张三第一批` 归张三，`李四第一批` 归李四。

有命名例外时，在第 2 步的「分组 → 归属人」框里写一行覆盖：

```
分组名=归属人
例：某某特批组=张三
```

归并结果会在「归并预览」表里实时显示，并标注是「自动」还是「手工」。

## 📊 输出结果

1. **统计周期横幅** — 日期范围、天数、来源文件（截图时在最上方）
2. **KPI** — 属于你的收益、甲方全表收入、你的占比、命中账号数、剧目数、播放量
3. **对账行** — 全表 − 排除 = 应付总盘，其中属于你多少
4. ① 按日期汇总　② 按归属人汇总　③ 按分组汇总　④ 按账号汇总
5. ⑤ 账号 × 剧目　⑥ 按剧目汇总　⑦ 原始明细
6. 未匹配账号清单 — 甲方表里不在你名单上的号，可一键转成名单格式回填

导出的 Excel 含以上全部 + 对账页，共 9 个 sheet，文件名形如 `短剧收益核算_2026-09-22.xlsx`。

## 🙋 常见问题

**Q：打开是空白 / 没反应？**　换 Chrome 或 Edge 打开；确认下载的是完整文件（约 900 KB，不是几 KB）。

**Q：列名没认出来？**　在第 1 步手动改那几个下拉框；表头不在第一行就改「表头所在行」。

**Q：名单能不能自动保存？**　会存在浏览器本地，下次打开自动带出。换电脑或清了浏览器缓存需要重贴。

**Q：手机上能用吗？**　不建议。本地 HTML 在手机上打开很别扭，导出的 Excel 也不好处理。

**Q：算出来的数和甲方给的对不上？**　先在「排除名单」里把甲方自有官方号填上，看「应付总盘」是否等于甲方给的金额；若还差，检查是不是有账号没进名单（看「未匹配账号」清单）。
